# Hospital-Emergency-Room-Dashboard
An end-to-end data analytics project using Python for EDA and data cleaning, Excel for interactive dashboard creation, and key healthcare insights.

# Overview
This project analyzes Hospital Emergency Room data to identify meaningful patterns and insights related to patient visits, waiting time, admission status, demographics, and patient experience.

The project follows an end-to-end data analytics workflow, from data loading and cleaning in Python to analysis and dashboard creation in Excel, followed by a project report and presentation using Gamma.

# Dataset

The dataset contains hospital emergency room patient and visit information.

Key Data Areas
Patient demographics
Patient age and gender
Visit details
Admission status
Waiting time
Patient satisfaction
Department/referral information
Date and time of visits

The exact number of rows and columns depends on the dataset used for the project.

# Exploratory Data Analysis

The dataset is explored to understand:

Number of records and columns
Data types
Missing values
Duplicate records
Statistical summaries
Distribution of important variables
Relationships between variables

# Excel Analysis

The cleaned dataset is imported into Excel for further analysis.

Excel is used for:

PivotTables
Calculations
Data summaries
Charts
KPI analysis

# Excel Dashboard

An interactive Hospital Emergency Room Dashboard is created to monitor key metrics such as:

Total Patients
Average Waiting Time
Average Satisfaction
Admission Rate
Patients by Gender
Patients by Age Group
Patients by Department/Referral
Patient Visits Over Time
Admission Status
